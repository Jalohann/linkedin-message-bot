# linkedin-message-bot

## Update - January 13th, 2025

While this project has been valuable for enhancing my knowledge of frontend frameworks and for practicing interaction through Selenium and Python, I’ve realized that its practical application can be counterproductive. Automating LinkedIn messages, though technically impressive, can come across as impersonal and even irritating to recruiters and hiring managers.

Over the last eight months, I’ve shifted to manually searching for jobs, applying, and sending personalized, non-AI messages. This approach has been far more successful than the one week I experimented with using this bot. Being authentic, genuine, and human in my communications has consistently fostered meaningful connections—an essential aspect of navigating today’s job market.

As a result, the OpenAI API key for this project has been revoked. Moving forward, this project will only serve as a demonstration of my skills in frontend development and working with the Selenium library to interface with LinkedIn.
